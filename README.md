🧠 Sexta-Feira — Sistema Neural Holográfico & Inteligência Orquestradora
Bem-vindo ao repositório oficial de engenharia visual, simulação biológica e arquitetura holográfica do Sexta-Feira e sua rede de agentes especializados.
🔬 Visão Geral do Projeto
Este projeto implementa uma simulação neural interativa de alta fidelidade visual, inspirada em biologia celular e em interfaces holográficas futuristas de HUD. Cada neurônio simula dinamicamente potenciais de ação, condução saltatória via bainha de mielina, sinapses químicas com exocitose vesicular e propagação de pulsos coloridos.
O sistema foi construído peça por peça de forma modular, garantindo que o núcleo central (Sexta-Feira) e seus agentes periféricos mantenham uma identidade anatômica rígida, adaptativa e limpa (sem sobreposições indesejadas).
