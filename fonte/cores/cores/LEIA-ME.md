# cores/cores

**O que faz**: as cores da tela (variáveis `--cor-...` do `cores.css`); é o único arquivo que o dono edita para mudar cores. O motor lê as mesmas variáveis (`dados/limpa` guarda os valores padrão).
**Porta**: nenhuma (CSS copiado como está). **Afeta todas**: mudar cor muda todos os pixels de referência (declarar `Pastas: cores`).
